# SEO keyword research — VeloceDrop

Updated: 2026-11-10. Market focus: Indonesia first, English pages for international discovery.

## What was checked

The owner chose to proceed with qualitative keyword research rather than supply Google Ads or Trends CSV exports. The Google Ads Keyword Planner requires an Ads account with billing setup to access keyword ideas and monthly search estimates. This plan therefore records intent-based candidates and does not invent volume, CPC, or competition values. Validate the candidate list in Keyword Planner with Indonesia / Indonesian and worldwide / English targeting before making paid-media decisions if measured bidding data is needed later.

Google Trends is a relative-interest tool, not a source of absolute search counts. Compare candidate groups in Explore using Indonesia, Web Search, and the same time window (start with 5 years, then 12 months); export the chart and related queries when reviewed. Google documents its 0–100 values as normalized to geography and time, and very low-volume terms can appear as zero.

Qualitative recommendation: lead Indonesian pages with task phrases used in everyday requests (`kompres foto`, `ubah ukuran foto`, `hapus latar`, `foto ke PDF`, `PDF ke JPG`), then state a specific constraint or output (`200 KB`, `3×4`, `HEIC ke JPG`, `4R/A4`) where the tool supports it. Keep English pages mapped to the equivalent action (`compress image`, `resize image`, `remove background`, `images to PDF`, `PDF to JPG`). These clusters reflect task intent and the product's actual functions; they are not ranked by measured demand.

## Keyword Planner workflow

1. In Google Ads Keyword Planner, use “Discover new keywords” with the candidate phrases above and the relevant landing page URL.
2. Set locations/languages separately for Indonesia / Indonesian and the intended English markets; do not combine them into one average.
3. Export average monthly searches, monthly trend, competition, and top-of-page bid ranges with the selected date range recorded.
4. Group terms by task intent, then map one primary phrase and useful secondary variants to each existing page. Keep copy natural and accurate to the tool’s limits.
5. Refresh this file with the dated export before claiming a phrase is high-volume or commercially valuable.

## Search and AdSense readiness limits

Search ranking, Google indexing, displayed favicons, and AdSense approval are not guaranteed by metadata or deployment. A production domain, public launch, Search Console verification, original useful content, and compliance with current AdSense policies remain operational prerequisites. Do not publish the `.example` placeholder as a canonical host.

Google Search's favicon eligibility is hostname-scoped: a GitHub Pages project URL under `username.github.io/repository/` is a subdirectory home page and is not eligible for a distinct project favicon in Google results. The 96 × 96 PNG is linked from the redirect root and localized home pages, but showing it for this project requires a custom domain or a Pages site at the hostname root. Googlebot must also be able to crawl both the home page and the favicon. See [Google's favicon guidelines](https://developers.google.com/search/docs/appearance/favicon-in-search).
