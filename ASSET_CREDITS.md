The YouTube channel banner preset follows the published [YouTube banner image guidelines](https://support.google.com/youtube/answer/10456525): recommended 2560 × 1440 px, minimum 2048 × 1152 px, and a 1235 × 338 px safe region at minimum size. The on-canvas guide scales that region proportionally to the recommended dimensions. Checked 2026-11-03.

`@jsquash/oxipng` 2.3.0 runs lossless PNG optimization in a browser worker under Apache-2.0. Its bundled Oxipng WebAssembly implementation is MIT licensed; retain the package and upstream Oxipng license notices when redistributing. The application asks for optimization level 4 with alpha optimization disabled to preserve pixel and transparency values.

The HEIC converter uses `heic-to` 1.6.7, licensed LGPL-3.0, with its bundled libheif decoder (the upstream release table maps this package version to libheif 1.23.7). The package chunk is dynamically loaded from the application origin; package and license are at `node_modules/heic-to`, and upstream sources are [heic-to 1.6.7](https://github.com/hoppergee/heic-to/tree/v1.6.7) and [libheif 1.23.7](https://github.com/strukturag/libheif/tree/v1.23.7). A copy of the LGPL license is served at `/licenses/heic-to-LGPL-3.0.txt`; `/licenses/heic-to-1.6.7-source.zip` contains the exact installed package license, source inputs and build script. The build recreates the archive from the locked dependency, and a unit test checks each source file against the installed package. Preserve both files and keep the decoder replaceable when redistributing. The decoder chooses the primary still (or first image when no primary is marked); motion tracks and auxiliary depth or portrait data are not exported. HEVC decoding may not support every HEIF variant.
